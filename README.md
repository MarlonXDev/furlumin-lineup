# Furlumin Lineup

Welcome, this repository stores the public DJ lineup data loaded by the [Furlumin](https://vrchat.com/home/world/wrld_...) world in VRChat.

The `lineup.json` file in this repo gets loaded live by the world's DJ Lineup Display script, so the schedule can be updated anytime without uploading the world again.
